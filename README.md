# Applied Mathematics Coursework

This repository contains selected computational coursework from undergraduate and graduate study in applied mathematics.

The work spans numerical analysis, ordinary differential equations, partial differential equations, and vector analysis, with most computational exercises implemented in MATLAB.

## Areas Covered

### Numerical Analysis

Topics include:

- polynomial interpolation;
- Newton's method;
- numerical quadrature;
- adaptive integration;
- Gaussian quadrature;
- approximation with orthogonal polynomials;
- numerical error and convergence analysis;
- numerical ODE methods;
- optimization and polynomial root distributions.

### Ordinary Differential Equations

Topics include:

- first- and higher-order ODEs;
- forced and damped systems;
- resonance;
- matrix-vector differential equations;
- comparison of analytical and numerical solutions;
- MATLAB's `ode45` solver;
- dynamical-system investigations.

### Partial Differential Equations

Topics include:

- heat and wave equations;
- finite-difference discretization;
- semidiscretization;
- Dirichlet, Neumann, and periodic boundary conditions;
- Fourier series;
- eigenfunction expansions;
- Bessel functions;
- Laplace and Poisson equations;
- inverse problems;
- numerical and analytic solution comparison.

### Vector Analysis

Topics include:

- vector fields;
- parameterized curves and surfaces;
- geometric visualization;
- applications of multivariable and vector calculus.

## Purpose

This repository preserves computational work completed while studying applied mathematics.

The code reflects the process of translating mathematical concepts into numerical algorithms, testing analytic results computationally, visualizing mathematical structures, and studying approximation and discretization methods.

Because the repository contains historical coursework, the code is presented primarily as evidence of mathematical and computational development rather than as a polished software library.

## Historical Notes

Some files were written for individual homework assignments and exams and retain their original academic filenames.

Several scripts depend on MATLAB functions or toolboxes that may not be available in all current MATLAB installations. The repository has been reorganized for clarity, but the original computational work has otherwise been preserved.
